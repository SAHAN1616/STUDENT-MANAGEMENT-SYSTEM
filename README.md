# EduManage – Student Management System

EduManage is a professional and responsive Student Management System designed to simplify and organize academic administration.

The system provides an easy-to-use admin dashboard for managing student records, attendance, marks and results, fees, teachers, reports, and system settings.

## 🚀 Features

- 📊 Admin Dashboard
- 👨‍🎓 Student Management
- 🗓️ Attendance Management
- 📚 Marks & Results Management
- 💳 Fee Management
- 👩‍🏫 Teacher Management
- 📈 Reports & Statistics
- ⚙️ System Settings
- 🔐 Admin Login
- 🗄️ MySQL Database Integration
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
- phpMyAdmin

## 💾 Database

The application uses MySQL for storing and managing:

- Student records
- Attendance records
- Marks and results
- Fee records
- Teacher records
- Admin information
- System settings

## 🎯 Purpose

The main purpose of EduManage is to provide a centralized digital platform for managing academic information efficiently, reducing manual record keeping, and making student management easier.
